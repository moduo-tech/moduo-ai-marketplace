# Research and attribution

The Moduo skills are original instructions informed by the sources below. No external skill is copied verbatim. GitHub star counts are discovery signals, not a quality or security guarantee; counts were checked on 2026-10-12.

| Source | Why consulted | License / status |
| --- | --- | --- |
| [Astro Agent Skills](https://github.com/incluud/astro-agent-skills) | Astro skill decomposition and version-aware documentation lookup (11 stars) | MIT |
| [Astro Skills](https://github.com/ianshk/astro-skills) | Astro static-site, image, and SEO scope (4 stars) | MIT |
| [Claude SEO](https://github.com/AgriciDaniel/claude-seo) | Broad SEO audit taxonomy (18.7k stars); only the technical subset is relevant here | MIT |
| [Playwright](https://github.com/microsoft/playwright) | Browser testing and screenshot comparison (97.5k stars) | Apache-2.0 |
| [Astro testing guide](https://docs.astro.build/en/guides/testing/) | Vitest and Playwright setup for Astro | Official documentation |
| [Google Search Central](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) | Search behavior and technical SEO checks | Official documentation |
| [Playwright accessibility testing](https://playwright.dev/docs/accessibility-testing) | Browser and axe-based accessibility checks with manual verification | Official documentation |
| [Astro i18n routing](https://docs.astro.build/en/guides/internationalization/) | Localized routes and link generation | Official documentation |
| [Astro content collections](https://docs.astro.build/en/guides/content-collections/) | Typed local and remote content contracts | Official documentation |
| [Astro with Strapi](https://docs.astro.build/en/guides/cms/strapi/) | CMS adapter patterns | Official documentation |
| [Web Vitals measurement](https://web.dev/articles/vitals-measurement-getting-started) | Lab and field performance interpretation | Official documentation |

The Astro-specific repositories found were small, so their content was checked against Astro's documentation and the real `moduo-landing` codebase. The no-inline-SVG and Tailwind-first rules come from Moduo's stated preferences, not from those projects or Astro itself.
